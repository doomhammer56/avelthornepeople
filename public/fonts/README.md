# PDF export font

`AvelthorneExport-Regular.ttf` is a regular-weight static derivative of Noto Sans SC
from the official Google Fonts repository, licensed under the included SIL OFL.
It retains the source font's encoded Unicode characters for bilingual exports.
It is fetched only when generating a PDF, not when loading public or admin pages.

Source revision: `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`

Source: <https://github.com/google/fonts/blob/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf>

Source SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`

FontTools was used to instantiate weight 400, remove layout alternates while
retaining encoded glyphs, and rename the derivative to Avelthorne Export Sans.
The original copyright and license are preserved in `OFL-NotoSansSC.txt`.
